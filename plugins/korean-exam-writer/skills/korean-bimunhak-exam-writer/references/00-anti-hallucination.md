# 00 · 환각 방지 프로토콜 (P0)

이 스킬의 존재 이유. "정확하게 써주세요" 같은 권고가 아니라 **기계로 검증 가능한 구조**로 강제한다.

## 반드시 거부(refuse)해야 하는 것
- **R1** 근거(A 교사 원문 / B 교사 자료 / C 인용된 `sources[]`)에 없는 **수치·연도·통계·인명·작품명·직접인용**을 단정.
- **R2** 근거가 뒷받침하지 않는 **인과·비교 주장**(`A 때문에 B`, `A가 B보다`).
- **R3** 모드 C에서 검색 근거가 없거나 인용 불가 → 지문 생성 거부, 모드 B로 강등(교사에게 자료 요청).
- **R4** 문항의 정답이 선언된 `evidenceLocations`로 도출되지 않거나, 오답이 실제로는 지문상 참인 경우.
- **R5** 근거 문장을 지문·선지에 **그대로 복사**(anti-copy). 단, 모드 A는 교사 원문 자체이므로 원문 표현 재사용 허용.

## 근거의 축자(verbatim) 인용 — H1 (핵심 방어선)
같은 LLM이 생성·검증하면 자기 환각을 "검증"할 수 있다. 그래서 **모델의 자기 진술을 믿지 않고**,
인용이 원본의 **실제 부분문자열**인지 스크립트가 대조한다.

- 지문의 모든 사실 문장(모드 B/C) → `sourceQuote`: 해당 `sources[]` 항목 `text`의 **글자 그대로의 부분문자열**.
- 각 문항 `evidenceLocations[].passageQuote` → 인용한 **지문 문장의 부분문자열**.
- 각 오답 `distractors[].whyFalseQuote` → 그 오답을 반증하는 **지문 문장의 부분문자열** (H5).
- 검증 사슬(스크립트가 대조): `문항.passageQuote ⊆ 지문 문장 ⊆ source.sourceQuote ⊆ 원자료`.
  하나라도 부분문자열이 아니면 **하드 실패** → 항목 제거/재생성.

## 생성/검증 분리 — H2
검증(4·6단계)은 **별도 패스**로, 적대적 태도로 수행한다:
"이 시험지를 깨뜨려라 — 원문에 글자 그대로 없는 주장, 실제로 참인 오답을 찾아라."
검증자는 생성자의 논리를 신뢰하지 말고 **원본으로부터 다시 도출**한다.

## 교사 신뢰 안전장치 — H4
모든 시험지에 교사용 **검증 리포트**를 첨부: 무엇을 점검했는지, 무엇을 제거·수정했는지, 저신뢰 항목,
그리고 문구 **"실제 출제 전 반드시 교사의 최종 검토가 필요합니다."** (학생 시트에는 인쇄되지 않음)

## 모드 C 근거 강도 — B1(사실엔 엄격, 서술엔 실용)
- 엄격 대상: **수치·연도·인명·통계·인용·인과 주장** → 반드시 `sourceQuote` 근거. 없으면 삭제.
- 완화 대상: 일반적 정의·잘 알려진 구조는 문장마다 인용 없이 서술 가능하되 **근거와 모순 금지**.
