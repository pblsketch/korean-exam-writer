# 24 · 외적 준거 `<보기>` 설계

> 수능 문학의 대표 문항 형태. `crosstext_integration` / `critical_evaluation` type과 짝을 이룬다.
> 독서의 `<보기>`가 *새로운 사례·자료*라면, 운문의 `<보기>`는 *읽는 틀*이다.

## 세 유형

| 유형 | `<보기>`가 제공하는 것 | 전형적 발문 |
|---|---|---|
| **비평 관점** | 작품을 읽는 이론적 틀 | "`<보기>`를 참고하여 윗글을 감상한 내용으로 가장 적절한 것은?" |
| **창작 배경** | 시대·전기적 맥락 | "`<보기>`를 바탕으로 윗글을 이해한 내용으로 …" |
| **비교 텍스트** | 다른 작품·산문 | "`<보기>`와 윗글을 비교한 내용으로 …" |

## 접지 규약 (H1-view)

`<보기>`의 내용도 **지어내면 안 된다.** 비평 관점을 쓴다면 그 관점이 실재해야 한다.

```json
"view": {
  "title": "보 기",
  "text": "이 시의 '사나이'는 우물에 비친 화자 자신의 모습이다. …",
  "sourceId": "s2",
  "sourceQuote": "우물에 비친 자신을 대상화하여 바라보는 자기 인식"
}
```

- `sourceId`가 있으면 `sourceQuote`가 그 소스의 **부분문자열인지 기계 검증**된다.
- 교사가 직접 쓴 관점이면 `sourceId`를 비우고 `sources`에 `teacher_material`로 등록한다.
- **금지**: 존재하지 않는 평론가·논문을 인용 형태로 지어내기. 출처를 못 대면 출처 없이
  교사 작성 관점으로 쓰고 그렇게 표시한다.

## 근거 구성 규칙

외적 준거 문항의 근거는 **양쪽에 걸쳐야** 한다.

```json
"evidenceLocations": [
  {"passageRef": "v0", "role": "external_criterion",
   "passageQuote": "자연을 함께 담아 내면을 비추는 거울로 기능한다",
   "interpretation": "<보기>가 제시한 틀 — 우물이 내면의 거울이라는 것."},
  {"passageRef": "p12", "role": "imagery_sensory",
   "passageQuote": "달이 밝고 구름이 흐르고 … 추억처럼 사나이가 있습니다",
   "interpretation": "자연물 나열 끝에 사나이를 놓는 배치가 그 거울 기능을 시행 차원에서 구현한다."}
]
```

**규칙**
1. `v0` 근거 **1개 이상** + 시행 근거 **1개 이상**. 둘 중 하나만 있으면 실격이다.
2. `<보기>`만 읽고 풀리면 시를 묻는 문항이 아니다. → 선지가 `<보기>`의 재진술이 되지 않게 한다.
3. 시행만으로 풀리면 `<보기>`가 장식이다. → 그럴 바엔 `<보기>` 없는 문항으로 낸다.
4. `<보기>`는 **해석을 지정**하되 **정답을 말하지 않는다.** "따라서 ③이 옳다" 수준으로 친절하면
   변별이 사라진다.

## `<보기>` 길이·형식

- 3~5문장, 150~300자. 길면 시보다 `<보기>` 읽기가 과제가 된다.
- 배점은 **3점**(`[3점]` 표기). 외적 준거 통합은 `integration` 이상이다.
- HWPX/HTML에서는 표 박스로 조판된다(`10-hwpx-mapping.md`).

## 오답 설계 (이 유형 특유)

외적 준거 문항의 오답은 **`<보기>`와 시의 연결을 비트는** 방식으로 만든다.

| recipe | 이 유형에서의 형태 |
|---|---|
| `causal_error` | `<보기>`가 말한 인과의 방향을 뒤집음 ("사나이가 나타났기 **때문에** 자기를 대상화하게 되었다") |
| `attribute_swap` | 보는 주체와 비치는 상을 교환 |
| `overgeneralization` | `<보기>`의 "교차하는 과정"을 "완결된 결말"로 확대 |
| `not_stated` | `<보기>`에도 시에도 없는 배경지식을 끌어옴 |
| `condition_confusion` | `<보기>`의 전제를 결론으로 사용 |

## 체크리스트

- [ ] `<보기>`가 실재하는 관점이거나 교사 작성임이 명시됐다.
- [ ] `sourceId`가 있으면 `sourceQuote`가 기계 검증을 통과한다. (H1-view)
- [ ] `v0` 근거와 시행 근거가 모두 있다.
- [ ] `<보기>`만으로도, 시만으로도 풀리지 않는다.
- [ ] `<보기>`가 정답을 직접 말하지 않는다.
