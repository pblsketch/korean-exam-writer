# 25 · 저작권 안전 (운문의 1차 관문)

> 독서는 지문을 **재구성**해서 저작권을 피한다. 운문은 작품 원문을 그대로 실으므로 그 우회가
> 불가능하다. 작품 선정이 곧 저작권 판단이다.

> ⚠️ 이 문서는 법률 자문이 아니다. 판단이 서지 않으면 **작품을 바꾸거나 교사 자료 경로로 간다.**

## 판단 순서

```
1) 교사가 적법하게 보유한 자료인가?      → kind: teacher_material, 진행
2) 저작자 사후 70년이 지났는가?          → kind: public_domain_work, copyright.basis 기재 후 진행
3) 둘 다 아니면                          → 거부. 교사에게 다른 작품이나 원문 제공을 요청
```

3번에서 **추측으로 진행하지 않는다.** "교육 목적이니 괜찮겠지"로 넘기지 마라 — 이 도구의 산출물은
파일로 저장되고 배포된다.

## 보호기간 계산 (한국 저작권법)

- 보호기간은 **저작자 사망 다음 해 1월 1일부터 기산**해 **70년**이다(제39조·제44조).
- 즉 **1955년 이전에 사망한 저작자의 작품은 2026년 현재 보호기간이 만료**됐다.
  (1955년 사망 → 1956.1.1 기산 + 70년 = 2025.12.31 만료)
- 공동저작물은 **마지막으로 사망한 저작자** 기준이다.

`copyright.basis`에는 **계산이 재현되도록** 쓴다:

```json
{"sourceId": "s1", "kind": "public_domain_work",
 "title": "윤동주, 「자화상」",
 "copyright": {"status": "public_domain",
               "basis": "저작자 윤동주 1945년 사망 — 사후 70년 경과(1946.1.1 기산, 2015.12.31 만료)"}}
```

`basis`가 비어 있으면 `validate_exam.py`가 **거부**한다(H7).

## 확인된 만료 작가 (2026년 기준, 예시)

| 작가 | 사망 | 대표작 |
|---|---|---|
| 김소월 | 1934 | 진달래꽃, 산유화, 초혼 |
| 이상 | 1937 | 오감도, 거울 |
| 윤동주 | 1945 | 자화상, 서시, 별 헤는 밤 |
| 한용운 | 1944 | 님의 침묵, 알 수 없어요 |
| 이육사 | 1944 | 청포도, 절정, 광야 |
| 정지용 | 1950 | 향수, 유리창 |

## 보호 중인 작가 (2026년 기준 — 원문 게재 불가)

| 작가 | 사망 | 만료 예정 |
|---|---|---|
| 김수영 | 1968 | 2039 |
| 박목월 | 1978 | 2049 |
| 김춘수 | 2004 | 2075 |
| 백석 | 1996 | 2067 |
| 서정주 | 2000 | 2071 |
| 신동엽 | 1969 | 2040 |

이 작가들의 작품은 **교사가 적법한 자료(교과서·구입한 시집 등)를 제공할 때만** 쓴다.
그 경우 `kind: teacher_material`로 등록하고, 산출물이 **교실 내 사용에 한정**됨을 고지한다.

## 고전시가

대부분 저작권이 소멸했다. 다만:
- **현대어 번역·주석·교주(校註)에는 별도의 저작권이 있을 수 있다.** 특정 출판본의 풀이를 그대로
  옮기지 말고 직접 풀거나 교사 자료를 받는다.
- 원문 표기는 저본에 따라 다르다. 어느 판본을 따랐는지 `sources[].title`에 적는다.

## 산출물 고지

`verificationReport.disclaimer`에 저작권 근거를 함께 싣는다. 시험지·해설지 말머리 배너는
독서와 동일하되, 작품 출처를 한 줄 덧붙인다:

```
※ 자동 생성 — 실사용 전 교사 검토 필수
※ 수록 작품: 윤동주 「자화상」(저작권 만료, 1945년 저작자 사망)
```

## 체크리스트

- [ ] 모든 작품 소스가 `teacher_material` 또는 `public_domain_work`다.
- [ ] `public_domain_work`마다 `copyright.basis`에 사망 연도와 계산이 있다. (기계, H7)
- [ ] 고전시가의 현대어 풀이를 특정 출판본에서 그대로 옮기지 않았다.
- [ ] 판단이 애매한 작품을 "아마 괜찮겠지"로 넘기지 않았다.
- [ ] 시험지에 작품 출처 고지가 실렸다.
