# 11 · 지문 전개(설명) 방식 팔레트 — 다양화 규칙

분야별 기본 공식(문제→원리→과정→변수→비교→한계, `05` 참조)은 **골격**일 뿐이다.
그 골격만 따르면 지문이 '나열·분류·구조 설명' 하나로 획일화된다. 실제 수능 비문학은 아래 **전개
방식**을 2~3개 **결합**하고, 지문마다 **주된 방식을 바꾼다**. 출제 시 반드시 이 팔레트에서 골라
다양화한다.

## 전개 방식 14종
| 방식 | 핵심 | 신호어·형태 |
|---|---|---|
| **정의·지정** | 개념의 뜻·범위를 규정 | "~란 …이다", "~를 …라 한다" |
| **예시·예화** | 추상 원리를 구체 사례로 | "예를 들어", "가령", 사례 삽입 |
| **비교·대조** | 둘 이상을 축을 세워 견줌 | "반면", "~와 달리", "공통점/차이" |
| **유추(analogy)** | 익숙한 것에 빗대 설명 | "마치 ~처럼", 구조적 대응 |
| **인과** | 원인↔결과 연결(정방향/역방향) | "때문에", "그 결과", "~에서 비롯" |
| **분석** | 전체를 구성 요소로 분해 | "~는 A, B, C로 이루어진다" |
| **분류·구분** | 기준으로 묶거나 나눔 | "~는 크게 …로 나뉜다" |
| **과정·절차** | 단계·시간 순 서술 | "먼저→다음→끝으로", 흐름 |
| **통시적 전개** | 역사적 변화·발전 서술 | "초기에는…이후…오늘날" |
| **문답(문제 제기)** | 질문을 던지고 답해 나감 | "그렇다면 왜?", "무엇이 …인가" |
| **변증(관점 대립)** | 주장→반박→종합 | "그러나 이에 대해…", 정반합 |
| **원리→적용** | 원리 제시 후 새 사례 적용 | "이 원리에 따르면…" |
| **통념 반박(교정)** | 흔한 오해를 뒤집음 | "흔히 …로 알지만 실은…" |
| **근거 제시(실증)** | 실험·통계·관찰로 뒷받침 | "한 연구에서…", 수치·설계 |

## 다양화 규칙
1. **주 전개 방식 1 + 보조 1~2** 를 조합한다(예: 통념 반박 + 인과 + 예시).
2. 같은 세트/같은 교사의 연속 지문은 **주 전개 방식을 서로 다르게** 한다.
3. **분류·나열만으로 지문을 채우지 않는다.** 나열은 정보 전달이지 사고를 요구하지 않는다.
4. 분야별로 잘 맞는 조합(권장):
   - 인문: 변증(관점 대립) + 정의 + 원리→적용 / 통시적 전개
   - 사회: 문제 제기 + 인과 + 조건·예외 + 사례
   - 과학·기술: 원리 + 과정·절차 + 근거(실증) + 비교 + 한계
   - 예술: 정의 + 유추 + 비교·대조 + 통시적 전개
   - 문학(비문학적 설명): 개념 정의 + 예시(작품) + 통념 반박
5. 난이도가 높을수록 **문답·변증·통념 반박·원리→적용**처럼 독자가 사고를 재구성해야 하는 방식을
   전면에 둔다(단순 정의·나열은 배경으로만).

## 자기 점검
지문을 쓴 뒤 스스로 묻는다: "이 글은 무엇을 '나열'했나, 아니면 무엇을 '규명·논증·적용'했나?"
후자가 아니면 전개 방식을 바꿔 다시 쓴다.
