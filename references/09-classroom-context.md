# 09 · 교실 맥락 수집 (인테이크)

오케스트레이터가 **가장 먼저** 교사에게 묻는 항목. 딸깍(한 번에 생성) 대신, 이 맥락을 대화로 모아
이후 모든 단계의 기준으로 삼는다. 이미 사용자가 말한 항목은 다시 묻지 않고, **빠진 것만** 묻는다.

## 필수 항목 (없으면 물어본다)
1. **학교급·학년** — 중1~고3 (지문 길이·통사 상한 결정, `06`)
2. **영역(비문학)** — 인문 / 사회 / 과학 / 기술 / 예술 (전개 공식·주제 성격, `05`)
3. **사용 목적** — 내신 대비 / 모의고사형 / 수업 활동·형성평가 / 보충·심화
4. **난이도** — 하 / 중 / 상 / 최상 (인지 출제 계약, `02`)
5. **학생 수준** — 상위권 / 중위권 / 기초 (난이도 미세 조정·어휘 수준)
6. **문항 수** — 그리고 `<보기>` 적용 문항 포함 여부
7. **지문 소스** — A 교과서 재구성 / B 교사 자료 재구성 / C AI 리서치 (`07`)
   - A·B면 원문/자료를 받는다. C면 주제 방향을 받는다.
8. **출력 형식** — 인쇄용 HTML(→PDF) / 한글(HWPX) / 둘 다

## 권장 항목 (있으면 품질↑, 없으면 기본값)
- **평가 목표(측정 능력)** — 사실 이해 / 관계·추론 / 원리 적용 / 비판적 읽기 중 무엇을 주로 볼지
- **교육과정 연계** — 특정 성취기준·단원·개념, 최근 수업 내용과의 연결
- **분량·시험 시간** — 지문 길이(중1~2 700자 ~ 고3 2000자), 배당 시간
- **금지·주의** — 피해야 할 주제/표현, 특정 배경지식 전제 금지 등
- **연계 지문** — 앞서 낸 지문과 주제 중복 회피, 통합형((가)/(나)) 필요 여부(고2+)

## 산출물 (context 객체)
수집 결과를 아래 형태로 정리해 이후 단계(자료조사·설계·집필·출제)에 전달한다.
```
{ grade, field, purpose, difficulty, studentLevel, questionCount, useView,
  sourceMode, outputFormat, goals, curriculum, length, constraints, priorTopics }
```

## 원칙
- **추측 금지**: 필수 항목이 비면 진행하지 말고 묻는다.
- **한 번에 몰아 묻지 말 것**: 2~4개씩 묶어 자연스럽게. 교사가 "알아서 해줘"라면 합리적 기본값을
  제안하고 **확인만** 받는다(그래도 학년·영역·소스는 반드시 확인).
- 이 맥락은 이후 **개요·지문·문항 검토 체크포인트**에서 판단 기준으로 재사용한다.
