# 08 · 검증 체크리스트 (게이트 1·2)

두 게이트는 기계 검증(`validate_exam.py`) + 의미 검증(LLM 적대적 재검토)의 결합이다.

## 게이트 1 — 사실 검증 (지문)
- [ ] 모든 사실 문장에 `sourceQuote`가 있고, 원자료의 **실제 부분문자열**이다. (기계)
- [ ] 근거 없는 수치·연도·인명·통계·직접인용이 없다. (의미)
- [ ] 인과·비교 주장이 근거로 뒷받침된다. (의미)
- [ ] 밑줄 표지 대상(span)이 실제 문장에 존재한다. (기계)
- 실패 → 해당 문장 수정/삭제(최대 2회), 못 고치면 지문 거부.

## 게이트 2 — 문항 품질 검증
- [ ] 정답이 정확히 1개이고, 선언된 `evidenceLocations`로 도출된다. (기계+의미)
- [ ] 각 오답이 지문 근거로 반증 가능하다(`whyFalseQuote`가 지문 문장의 부분문자열). (기계)
- [ ] 실제로는 참인 오답이 없다. (의미)
- [ ] 지문 밖 배경지식 없이 풀린다. (의미)
- [ ] 발문·지문·선지에 모순/복수정답이 없다. (의미)
- [ ] 난이도 계약 충족: 근거 수 ≥ 최소, 도출 단계 ≥ 최소. (기계)
- [ ] 유형이 배분표와 맞고 중복되지 않는다. (기계)
- [ ] 약한 오답(`weakDistractorIndexes`)이 2개 미만이다. (기계)
- 실패 → 해당 문항만 재생성(최대 2회), 못 고치면 제거(요청 수 미달 시 부족분을 보고, 지어내지 말 것).

## 교사 검증 리포트(H4)
`verificationReport`에 각 점검 항목의 ok/detail, 제거·수정 항목, 저신뢰 플래그, 그리고 고지문을 채운다:
> "본 시험지는 AI가 보조 생성한 것으로, 실제 출제 전 반드시 교사의 최종 검토가 필요합니다."

## 실행 명령
```
python scripts/validate_exam.py exam.json   # exit 0 이어야 렌더링 진행
```
exit 0이 아니면 출력된 오류 리포트의 id·rule대로 고쳐 재검증한다.
